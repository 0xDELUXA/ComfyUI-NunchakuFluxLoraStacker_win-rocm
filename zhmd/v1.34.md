# 调查与解决报告：ColorFilter 排除词失效问题

本文件提供了关于在 `ColorFilter` 节点的 `exclude_words` 输入参数中指定的自定义词（例如 `"blonde"`）未能从提示词输出中排除的问题的技术概述，以及详细的分析、根本原因、修改的文件、完整的源代码和逻辑的详细解释。

---

## 1. 问题描述

在 ComfyUI 中运行 `ColorFilter` 节点时，当输入结构包含 `exclude_words`（例如 `"blonde, glasses,"`）时，单词 `"blonde"` 未能从最终的输出文本中过滤掉。用户观察到，尽管指定了 `"blonde"` 作为排除词，输出字符串中仍然包含该单词，并且逗号周围的格式变得畸形（留下了连续的悬空逗号）。

---

## 2. 根本原因分析

我们确定了共同导致此错误的两个不同原因：

### 原因 A：过期的 Python 字节码缓存（`__pycache__`）
* **底层问题：** 目录 `nodes/color_filter/__pycache__/` 包含了在引入 `exclude_words` 输入功能之前编译的 `.pyc` 文件。
* **机制：** 当 ComfyUI 导入 `ColorFilter` 节点时，Python 加载了过期的编译字节码（`.pyc`），而不是解析更新后的源代码（`.py`）。因为旧的类签名在 `INPUT_TYPES` 中缺少 `exclude_words` 输入，并且在 `filter_text` 方法中缺少 `exclude_words` 参数，ComfyUI 默默地忽略了任何连接到 `exclude_words` 的输入，并完全绕过了自定义排除逻辑。
* **解决方案：** 我们删除了过期的 `__pycache__` 目录，强制 Python 运行时重新解析源代码并生成与更新后的类签名相匹配的、全新的、正确的字节码。

### 原因 B：单次处理的逗号清理正则表达式
* **底层问题：** 当排除多个连续单词时（例如，从 `"blonde, glasses, photo of..."` 中同时移除 `"blonde"` 和 `"glasses"`），它们的移除会留下多个由空格分隔的相邻逗号（例如 `, , ,`）。
* **机制：** 原本的清理模式为：
  ```python
  filtered_text = re.sub(r",\s*,", ",", filtered_text)
  ```
  由于 `re.sub` 在单次非重叠处理中执行，三个或更多逗号的序列仅被部分折叠（例如，`, , ,` 变为 `, ,`），在最终的提示词中留下了孤立的逗号。
* **解决方案：** 我们将单次替换替换为迭代 `while` 循环，该循环反复运行，直到字符串稳定且不再有连续逗号。

---

## 3. 修改的文件

* **文件路径：** `nodes/color_filter/color_filter.py`
* **做出的更改：**
  1. 删除过期的 `__pycache__` 目录以强制重新编译。
  2. 修改了 `nodes/color_filter/color_filter.py` 中的逗号折叠块，以使用迭代 `while` 循环。

---

## 4. `color_filter.py` 完整源代码

以下是包含修复的 `nodes/color_filter/color_filter.py` 的完整源代码：

```python
"""Remove monochrome / B&W related phrases from caption or prompt text."""

import re


class ColorFilter:
    def __init__(self):
        pass

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "text": ("STRING", {"multiline": True}),
                "exclude_words": ("STRING", {"default": ""}),
            }
        }

    RETURN_TYPES = ("STRING",)
    RETURN_NAMES = ("filtered_text",)
    FUNCTION = "filter_text"
    CATEGORY = "Text/Filter"

    def filter_text(self, text, exclude_words=""):
        keywords_to_remove = [
            r"\bwhite and black\b",
            r"\bblack and white\b",
            r"\bmonochrome\b",
            r"\bgrayscale\b",
            r"\bgrey scale\b",
            r"\bgreyscale\b",
            r"\bB&W\b",
            r"\bdesaturated\b",
            r"\bblonde\b",
            r"\bblonde hair\b",
            r"\bachromatic\b",
            r"白黒",
            r"モノクロ",
            r"グレースケール",
            r"無彩色",
            r"セピア",
        ]

        user_patterns = []
        if exclude_words:
            # Split by comma or newline
            for word in re.split(r'[,\n]', exclude_words):
                word = word.strip()
                if not word:
                    continue
                
                # Escape string for regex
                escaped_word = re.escape(word)
                
                # Append word boundary (\b) only if the word starts/ends with ASCII alphanumeric characters
                start_boundary = r"\b" if re.match(r'^[a-zA-Z0-9_]', word) else ""
                end_boundary = r"\b" if re.search(r'[a-zA-Z0-9_]$', word) else ""
                
                pattern = f"{start_boundary}{escaped_word}{end_boundary}"
                user_patterns.append(pattern)

        keywords_to_remove = user_patterns + keywords_to_remove

        # Sort patterns by the length of the actual matched text in descending order
        # to ensure longer phrases (e.g. "blonde hair") are removed before shorter sub-words (e.g. "blonde")
        keywords_to_remove.sort(
            key=lambda p: len(re.sub(r"\\(.)", r"\1", p.replace(r"\b", "").replace(r"\ ", " "))),
            reverse=True
        )

        filtered_text = text
        for keyword in keywords_to_remove:
            filtered_text = re.sub(keyword, "", filtered_text, flags=re.IGNORECASE)

        # Collapse multiple commas, spaces, and strip leading/trailing commas and spaces
        prev = None
        while prev != filtered_text:
            prev = filtered_text
            filtered_text = re.sub(r",\s*,", ",", filtered_text)
        filtered_text = re.sub(r"\s+", " ", filtered_text)
        filtered_text = filtered_text.strip(" ,")

        return (filtered_text,)
```

## 5. 代码的详细说明

### 5.1 定义输入配置 (`INPUT_TYPES`)
```python
    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "text": ("STRING", {"multiline": True}),
                "exclude_words": ("STRING", {"default": ""}),
            }
        }
```
ComfyUI 查询 `INPUT_TYPES` 来构建 UI 节点控件。
* `text` 接收目标字符串（例如，来自标记模型的生成描述）。
* `exclude_words` 接收包含要移除的自定义词的字符串输入，默认为空。

### 5.2 动态正则解析与单词边界保护
```python
        user_patterns = []
        if exclude_words:
            # Split by comma or newline
            for word in re.split(r'[,\n]', exclude_words):
                word = word.strip()
                if not word:
                    continue
                
                # Escape string for regex
                escaped_word = re.escape(word)
                
                # Append word boundary (\b) only if the word starts/ends with ASCII alphanumeric characters
                start_boundary = r"\b" if re.match(r'^[a-zA-Z0-9_]', word) else ""
                end_boundary = r"\b" if re.search(r'[a-zA-Z0-9_]$', word) else ""
                
                pattern = f"{start_boundary}{escaped_word}{end_boundary}"
                user_patterns.append(pattern)
```
* **分割：** 来自 `exclude_words` 的输入通过逗号或换行符进行分割。
* **转义：** 我们应用 `re.escape` 以防止任何字符（如括号或方括号）被解释为有效的正则分组/操作符，这会破坏执行。
* **条件边界 (`\b`)：** 我们检查单词是否以 ASCII 字母数字字符开头或结尾。单词边界选择器 `\b` 匹配单词字符 (`\w`) 与非单词字符之间的边界。将其无条件应用于非 ASCII/CJK 字符（如日语汉字/假名）会由于 CJK 字符不在标准 ASCII 字母数字范围内而阻止匹配。这种动态配置防止了混合语言提示中的边界错误。

### 5.3 基于长度排序策略
```python
        # Sort patterns by the length of the actual matched text in descending order
        # to ensure longer phrases (e.g. "blonde hair") are removed before shorter sub-words (e.g. "blonde")
        keywords_to_remove.sort(
            key=lambda p: len(re.sub(r"\\(.)", r"\1", p.replace(r"\b", "").replace(r"\ ", " "))),
            reverse=True
        )
```
* 如果在 `"blonde hair"` 之前匹配并替换了像 `"blonde"` 这样较短的模式，短语 `"blonde hair"` 将变为 `" hair"`，留下不需要的悬空单词。
* 为了防止这种情况，我们获得每个模式的字面长度（忽略诸如 `\b` 和转义斜杠 `\` 之类的结构正则元数据），并按降序对组合关键字数组进行排序。这确保了更长、更具体的短语被首先处理和移除。

### 5.4 迭代多轮清理循环
```python
        # Collapse multiple commas, spaces, and strip leading/trailing commas and spaces
        prev = None
        while prev != filtered_text:
            prev = filtered_text
            filtered_text = re.sub(r",\s*,", ",", filtered_text)
        filtered_text = re.sub(r"\s+", " ", filtered_text)
        filtered_text = filtered_text.strip(" ,")
```
* **迭代逗号折叠：** `while prev != filtered_text` 循环确保了相邻逗号的连续运行（例如 `, , ,`）在多轮处理中被折叠，直到没有两个逗号仍然被空格分隔。
* **空格规范化与去除：** 连续的空格被减少为单个空格，并且开头或结尾的空格/逗号被清理，留下一个干净、有效的提示词字符串。
