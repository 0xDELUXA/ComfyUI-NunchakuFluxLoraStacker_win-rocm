# 调查与解决报告：缺少 `pytorch_lightning` 导致整包无法导入（Issue #5）

本文说明为何缺少 **`pytorch_lightning`** 会使 ComfyUI **无法加载整个** `ComfyUI-NunchakuFluxLoraStacker` 自定义节点包（而不仅是 CCSR），**v1.38** 做了哪些修改，以及用户 / ComfyUI-Manager 如何获得修复。

**相关议题：** [Issue #5](https://github.com/ussoewwin/ComfyUI-NunchakuFluxLoraStacker/issues/5)

---

## 1. 问题描述

在 **ComfyUI-Easy-Install** 等环境中，启动日志出现：

```text
[WARNING] Cannot import ...\ComfyUI-NunchakuFluxLoraStacker module for custom nodes:
No module named 'pytorch_lightning'
```

该警告之后，本包的 **所有节点** 都不会出现在界面中——FLUX LoRA 加载器、Florence-2、Resolution Selector、CCSR 全部不可用。即使从不使用 CCSR 的用户，也会失去整个扩展。

---

## 2. 根本原因分析

### 原因 A：在顶层急切导入 CCSR

根目录 `__init__.py` 在包加载时导入 CCSR：

```python
from .nodes.CCSR import NODE_CLASS_MAPPINGS as CCSR_NODES, NODE_DISPLAY_NAME_MAPPINGS as CCSR_NAMES
```

ComfyUI 通过执行该模块来加载自定义节点。只要 **任意** 顶层 import 抛错，ComfyUI 就会丢弃 **整个** 包。

### 原因 B：CCSR 导入链依赖 `pytorch_lightning`

CCSR 子树（源自 [kijai/ComfyUI-CCSR](https://github.com/kijai/ComfyUI-CCSR)）会较早导入 Lightning，例如：

```text
nodes/CCSR/… → ddpm_ccsr_stage1.py → import pytorch_lightning as pl
```

若 ComfyUI 的 venv 中未安装 `pytorch_lightning`，该导入会抛出 `ModuleNotFoundError`。

### 原因 C：根目录未声明依赖

`nodes/CCSR/requirements.txt` 已列出 CCSR 依赖（含 `pytorch-lightning>=2.2.1`），但 ComfyUI-Manager / Easy-Install 使用的 **根目录** `requirements.txt` **没有** 这些项。根目录也 **没有** `install.py`，无法在 Manager 安装/更新时自动安装。

已安装 Lightning（或手动装过 CCSR 依赖）的环境不会复现——因此在 Issue #5 出现之前容易被忽略。

---

## 3. v1.38 的变更

### 3.1 根目录 `requirements.txt`

增加 CCSR 依赖块（与上游 CCSR / `nodes/CCSR/requirements.txt` 对齐）：

```text
# CCSR upscaler (nodes/CCSR) — required at pack import time
# Without these, ComfyUI fails to load the entire custom node pack (see issue #5)
taming-transformers
omegaconf
einops
pytorch-lightning>=2.2.1
open-clip-torch>=2.23.0
```

### 3.2 新增 `install.py`（ComfyUI-Manager 钩子）

在根目录新增 `install.py`，使 Manager 的 **安装 / 更新** 在当前 ComfyUI 解释器中执行：

```text
python -m pip install -r requirements.txt
```

从而在 Manager 操作后确保 Lightning 及其他 CCSR 包存在。

---

## 5. 如何应用

1. **更新本自定义节点**（git pull / ComfyUI-Manager Update）。
2. 若 Manager 未自动运行 `install.py`，在 ComfyUI 的 Python 环境中执行：

```bash
python -m pip install -r requirements.txt
```

3. **完全重启 ComfyUI**，确认不再出现 `pytorch_lightning` 警告且本包可加载。

已安装 Lightning 的环境只需更新仓库文件即可。
