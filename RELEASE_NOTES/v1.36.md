## LoRA Stacker V3

Added **LoRA Stacker V3** (`LoraStackerV3_10`) for standard SD models—the same 10-slot stack as V2, plus a **global `toggle_all` master switch** (when off, no LoRAs are applied and outputs pass through unchanged) and **per-slot `enabled_1` … `enabled_10` toggles** for quick A/B comparisons and partial stacks without rewiring. Implemented in `nodes/lora/standard_v3.py`; README documents usage and the toggle truth table.
